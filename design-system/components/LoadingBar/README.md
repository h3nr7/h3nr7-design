# LoadingBar

A fixed 2px line across the top: a `colour-line` track with a 40% ink segment sweeping across in 1100ms. Only while something actually loads.

`<div class="h3-loading-bar" role="progressbar" aria-label="Loading"></div>`

Under reduced motion it becomes a still bar.

Source: `skills/h3nr7-design/assets/h3nr7.css` and `references/components.md` in h3nr7/h3nr7-design.
