# Footer

The closing line of a page: `text-sm`, `colour-ink-faint`, with links in ink so the actionable words are the darkest in the sentence. Preceded by `.h3-rule.h3-rule-close`.

## Markup

```html
<span class="h3-rule h3-rule-close" role="presentation"></span>
<footer class="h3-footer"><p>Drop me an <a href="mailto:…">email</a> for the full CV.</p></footer>
```

Faint text is 3.2:1 on the light page: keep it to one short closing line, never body copy. A friendly closer, not a call to action.
