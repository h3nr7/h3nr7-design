# Cta

The one filled action on a page — `colour-accent` ground, `colour-accent-ink` text, padding `space-2 space-4`, `radius-md`, as wide as its label.

## Markup

`<a class="h3-cta" href="/">Back to home</a>`

Hover and focus invert it to the `colour-hover` ground with ink text. One per page at most (an error page's "Back to home"). A short imperative label; never "Get started".
