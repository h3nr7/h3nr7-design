# SectionLabel

A section heading set as a small signpost: Inter, `text-sm`, uppercase from CSS, tracked 0.08em, `colour-ink-faint`.

## Markup

`<h2 class="h3-label">Experience</h2>` — inside `.h3-prose` every `h2` takes this automatically. `space-12` above, `space-4` below.

## Rules

- Structurally a heading, typographically the smallest thing in its section; the entry title under it is the largest. That inversion is deliberate.
- Write the source text in sentence case ("Experience"); the uppercase comes from CSS.
- Never Mrs Eaves — tracking would break its ligatures, and caps labels are always Inter.
