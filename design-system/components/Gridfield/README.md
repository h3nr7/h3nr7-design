# Gridfield

The only acceptable empty-image state: `gridfield` near-black with 1px `gridfield-line` lines every 14px, and the piece's initials centred (`.h3-monogram`: display italic, lining figures, ligatures on, 30px, `monogram` white 82%). It is the site's WebGL wireframe seen head-on.

## Markup

`<div class="h3-gridfield" style="aspect-ratio:16/9"><span class="h3-monogram">TT</span></div>`

Fixed colours: it does not flip in dark mode. No stock imagery, gradients or glows instead.

Source: `skills/h3nr7-design/assets/h3nr7.css` and `references/components.md` in h3nr7/h3nr7-design.
