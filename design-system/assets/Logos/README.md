# Logos

The stacked **h3r / n7** mark — "h3nr7" in Mrs Eaves OT Bold Italic, type converted to outlines, generated from the Illustrator master. Artwork, not type: place the file, never retype or redraw it.

- `h3nr7-mark.svg` — tight to the ink, `fill="currentColor"`. Inline it in HTML so it follows the theme; as an `<img>` it draws black.
- `h3nr7-mark-black.svg` / `.png` — fixed `logo-black`, transparent. For light grounds; PNG (896×1200) for Office.
- `h3nr7-mark-white.svg` / `.png` — fixed `logo-white`, transparent. For dark grounds (invisible on a light tile preview).
- `h3nr7-tile-dark.svg` / `.png` — white mark on a black 1080² square: the avatar, social card and og:image. `-1280.png` is the site's own og:image copy.
- `h3nr7-tile-light.svg` / `.png` — black on white, for light contexts that need a square.
- `h3nr7-glyph.svg` / `.png` — the favicon: a square's bottom-right half, `currentColor` (draws black as `<img>`). At or below 32px only; not a bullet or divider.

Rules: black (or ink) on light grounds, white on dark — no greys, colours, gradients, outlines, shadows, rotation or distortion. Clear space at least the width of the mark's "n" on every side (the tiles show it: the mark fills ~51% of the width). Below ~48px tall (12mm in print), use the glyph.
